# frxy-skin-tools

在 Blender 中修改并替换《非人学园》同名模型。

本仓库提供 NeoX 皮肤导出与回装插件，以及实验性 MMD 蒙皮适配功能。

当前版本：**0.5.0 实验版**。MMD 蒙皮适配已完成部分本地检查，尚未完成完整游戏动作、局内实战、表情和附属物理验收。

## 下载与安装

1. 下载 [NeoX 皮肤导出插件 v0.5.0.zip](dist/NeoX_皮肤导出插件_v0.5.0.zip)。在 GitHub 文件页点击下载原始文件。
2. 保存当前 Blender 工程，在插件设置中选择“从磁盘安装”，选中上述 ZIP，然后启用“NeoX 皮肤导出与回装”。
3. 重启 Blender，在三维视图按 `N`，打开“NeoX 导出”。
4. 根据自己的电脑修改工程保存位置、骨骼映射配置路径，以及插件偏好设置中的 MuMu 目录、实例编号和游戏包名。

此包保持原 0.5.0 内容不变，默认路径包含开发电脑的 `C:\WORK\Chatgpt` 和 MuMu 路径。安装前请核对自己的路径。插件声明 Blender 最低版本为 4.2；这不代表所有 Blender 版本均已验证。随包 ASTC 编码器为 Windows x64 版本。

## 功能

- 使用原始 CMesh/GIM/MTG 模板导出修改后的网格与材质、配套贴图。
- 原生骨架模型同名回写，以及新名称的皮肤资源输出。
- 基础颜色贴图、UV 处理与 ASTC 编码。
- 实验性 MMD 骨骼对应、体型和绑定姿势调整、权重转换、关节测试。
- 工程记录、MuMu 安装前备份、安装文件校验和恢复。

## 基本流程

1. 准备目标角色未修改的原始资源，区分局外展示与局内模型。
2. 选择源模型，选择对应的目标 `.cmesh`；同目录需有配套 `.gim`、`.mtg` 和依赖贴图。
3. 原生模型使用原骨架流程；MMD 模型明确选择“MMD 动作适配（实验）”，点击“准备动作副本”。
4. 检查贴图、体型和关节变形；必要时修改生成副本的网格或权重。
5. MMD 副本微调后，直接“导出当前适配副本”。重新准备会生成新副本，不保留先前副本的手工微调。
6. 同名导出成功后，关闭游戏，使用“备份并安装到 MuMu”。重新启动游戏检查效果。
7. 局外与局内分别制作、分别验收。独立武器、伙伴等资源需分别处理。

## 当前限制

- “新皮肤资源”只生成新文件，不会自动新增游戏皮肤选择入口；不支持自动新增独立角色。
- 不转换完整 PMX 刚体/关节、VMD、表情动画或游戏附属物理配置。
- Blender 关节测试不等于游戏动画验收；本地导出通过不等于游戏中全部动作正常。
- 不要修改生成骨架的静止位置、方向、层级和骨骼编号。
- 只支持现有写入器覆盖的 v4、flag 4/5、单分段 CMesh；骨骼最多 254 根，UV/法线拆分后的输出顶点少于 65536。
- 基础颜色模板不能完整还原任意复杂着色器。

详细操作见 [随包使用说明](neox_skin_exporter/使用说明.md)，验证范围见 [兼容性与验证报告](neox_skin_exporter/兼容性与验证报告.md)。这些文档是原版本的开发记录，提到的本地示例模型、绝对路径和截图不包含在此仓库中。

## 仓库内容

- `neox_skin_exporter/`：插件源码、随包说明和 ASTC 编码器。
- `dist/`：可安装 ZIP 和 SHA-256 校验文件。
- `scripts/build_package.py`：从源码目录重新生成插件 ZIP。

重打包：在仓库根目录运行 `python scripts/build_package.py`。该脚本只打包插件，不运行 Blender 或安装到游戏。

仓库不包含游戏模型、游戏贴图、MMD 素材、Blender 示例工程和设备备份。
